## Comparación de instrucciones en Python, JavaScript y C#

| Instrucción | Python | JavaScript | C# |
|---|---|---|---|
| Mostrar un mensaje | `print("Hola")` | `console.log("Hola");` | `Console.WriteLine("Hola");` |
| Guardar una variable | `nombre = "Luis"` | `let nombre = "Luis";` | `string nombre = "Luis";` |
| Leer datos del usuario | `input("Tu nombre: ")` | `prompt("Tu nombre:");` | `Console.ReadLine();` |
| Condicional | `if edad >= 18:` | `if (edad >= 18) { }` | `if (edad >= 18) { }` |
| Ciclo repetitivo | `for i in range(5):` | `for (let i = 0; i < 5; i++) { }` | `for (int i = 0; i < 5; i++) { }` |
| Crear una función | `def saludar():` | `function saludar() { }` | `void Saludar() { }` |

### Conclusión

Python, JavaScript y C# permiten realizar tareas similares, como mostrar mensajes, guardar datos, tomar decisiones, repetir instrucciones y crear funciones. Sin embargo, cada lenguaje tiene su propia sintaxis y forma de escribir el código.
